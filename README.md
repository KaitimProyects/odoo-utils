# odoo-utils

Utility modules for Odoo by [Kaitim](https://www.kaitim.com), free to use under LGPL-3.

Each branch targets one Odoo version; this one is Odoo 18.

## Modules

| Module | Summary |
|---|---|
| [ktm_stock_inventory_importer](ktm_stock_inventory_importer/) | Validate a physical inventory Excel file before loading it |

## Installation

Clone the repository and add its directory to `addons_path`; every module sits at the top level.

```bash
git clone -b 18 git@github.com:KaitimProyects/odoo-utils.git
```
